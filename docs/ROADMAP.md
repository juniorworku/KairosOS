# Roadmap

The implementation guide remains the detailed source of requirements. This file records delivery scope, not acceptance results.

| Milestone | Scope | State |
| --- | --- | --- |
| M0 | Repository, local services, typed API/UI foundation, migration baseline, generated client and checks | Current delivery; see verification report |
| M1 | Google + magic-link authentication, users/roles, settings, ownership, export/delete | Planned |
| M2 | Seasons, goals, GPS wizard, actions, obstacles, check-ins | Planned |
| M3 | Calendar availability with separate consent and encrypted tokens | Planned |
| M4 | Deterministic scheduler, manual busy input, review and capacity warnings | Planned |
| M5 | Accepted calendar writes, idempotent publish and reconciliation | Planned |
| M6 | Focus timer/logging, self-ratings, trajectory and calibration | Planned |
| M7 | Optional AI coach, validated suggestions, quotas and AI-off mode | Planned |
| M8 | PWA offline behavior, accessibility/performance and security hardening | Planned |
| M9 | Chrome extension pairing and session-limited domain blocking | Planned |
| M10–M17 | Opt-in Personal Mode, companion, automations and activity tools | Deferred until M9 |

Deployment is explicitly deferred. No staging or production release runs from CI.
